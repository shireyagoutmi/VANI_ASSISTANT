# VANI - Personal AI Assistant

VANI is a Telegram-integrated personal AI assistant built to handle everyday tasks, reminders, and conversations through natural language — combining LLM intelligence with practical automation.

## 🌟 Features

- **Conversational AI** — Powered by Claude/OpenAI APIs for natural, context-aware conversations
- **Telegram Integration** — Accessible directly through Telegram
- **Voice Support** — Speech-to-text via Whisper and text-to-speech via ElevenLabs
- **Persistent Memory** — Uses ChromaDB for context retention across conversations
- **Task Scheduling** — Automated reminders using APScheduler
- **Safety-First Actions** — Confirmation gate for risky actions before execution

## 🛠️ Tech Stack

- **Backend Framework:** FastAPI
- **AI/LLM:** Claude API, OpenAI API
- **Database:** SQLite, ChromaDB
- **Task Scheduling:** APScheduler
- **Speech Processing:** Whisper, ElevenLabs
- **Messaging Platform:** Telegram Bot API
